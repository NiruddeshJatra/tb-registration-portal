TB Registration Portal · Design Spec · v1 · Jul 2026

Start Line / Night Ops

Two surfaces, one system. The public wizard is a race bib: warm paper, hard ink, electric chartreuse, condensed numerals. The admin is a night timing board: the same chartreuse as telemetry on near-black ink. Implementable directly against Tailwind v4 + shadcn/ui.

1 · Tokens

Drop-in replacement for the :root block in src/index.css. Public pages use the light set; wrap /admin in .dark.
